# Generative AI Study Materials & Notes

A private repository for curating personal study materials, research summaries, architectures, notes, and code experiments across Generative AI and Machine Learning.

---

## 📚 Structure Overview

- **`01_foundations/`**: Linear algebra, probability, deep learning foundations, transformer fundamentals.
- **`02_llm_architectures/`**: Attention mechanisms, decoder-only vs. encoder-decoder, MoE (Mixture of Experts), state-space models (Mamba).
- **`03_training_and_fine_tuning/`**: Pre-training, SFT, LoRA/QLoRA, RLHF, DPO, GRPO, optimization techniques.
- **`04_rag_and_vector_dbs/`**: Vector embeddings, semantic search, hybrid retrieval, reranking, agentic RAG workflows.
- **`05_ai_agents/`**: Multi-agent systems, tool use, reasoning frameworks (ReAct, Tree of Thoughts, CoT), orchestrators.
- **`06_multimodal_models/`**: Vision-Language models (VLMs), audio/speech models, diffusion and generative image/video.
- **`07_deployment_and_inference/`**: Quantization (AWQ, GPTQ, GGUF), vLLM, TensorRT-LLM, speculative decoding, cost & latency optimization.
- **`08_papers_and_readings/`**: Key research papers breakdown, reading notes, and annotated bibliography.
